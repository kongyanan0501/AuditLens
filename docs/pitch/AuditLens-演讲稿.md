## 第 1 页｜封面

各位评委好。我是 Yana Kong。  
今天介绍的作品是 **AuditLens AI**——智能财务风险审计工作台。

一句话概括：上传财务流水，几分钟内完成规则检测与异常发现，用 AI 结合制度做解释，并进入整改闭环，最后留下可归档底稿。

说明材料按参赛要求组织：作品名称、适用场景、主要功能、使用工具、数据来源、预期价值、推广可能；另外补充一页使用方法，方便评委快速理解怎么用。

## 第 3 页｜作品名称

AuditLens AI 面向企业内审与财务合规。

我们刻意强调三件事：

1. **不是 Chat 套壳**——规则与评分可复现，AI 只做制度增强解释；  
2. **不是只出报告**——从发现到整改验收形成完整闭环；  
3. **不是空中楼阁**——证据链、角色权限、底稿元数据，对准内审真实工作方式。

---

## 第 4 页｜适用场景

三类用户、三种用法：

- **审计人员**：周期抽检或专项核查时，做全量风险扫描、确认或标误报、分派整改、验收关单；  
- **业务对接人**：收到分派后，只看自己的工单，提交说明与附件，等待审计验收；  
- **管理层**：看 Executive Brief——综合评分、高风险数量、优先整改 Top3。

我们不做万能 GRC 平台，先做企业内可用、能演示、能闭环的最小工作台。

---

## 第 5 页｜主要功能

核心能力有六块：

1. LangGraph 编排的六节点流水线：Parse → Rule → Anomaly → Score → RAG → Report；  
2. 规则与异常检测：重复发票、审批缺失、金额离群、供应商集中；  
3. 制度增强解释：RAG 检索本公司条款，LLM 只解释「为何可疑」，不替代判责；  
4. Issue 工作台：按严重度筛选，展开即见证据快照；  
5. 工单闭环与角色隔离：待复核到关闭全流程留痕，审计与业务通过 RLS 隔离；  
6. 正式报告导出：可下载、复制、打印带走。

关键原则：**规则判风险，LLM 只解释**。

---

## 第 6 页｜使用方法

实际操作五步：

1. **登录上传**——上传 Excel 或 CSV，也可用演示样例；  
2. **自动审计**——系统跑完流水线，进入 Dashboard 看风险总览；  
3. **复核证据**——展开高风险项，看关联凭证、规则命中和制度解释；  
4. **分派整改**——确认风险后分派业务；业务提交说明与附件，由审计验收；  
5. **导出报告**——验收关闭后导出正式报告，作为底稿归档。

如果现场 Demo，前三步两分钟内可以走完。

## 第 7 页｜使用工具

工程上是可演进的全栈骨架：

- 前端与 API：Next.js、TypeScript、React；  
- 编排：LangGraph 六节点；  
- 数据与鉴权：Supabase Postgres、Auth、RLS；  
- 规则与评分：自研规则引擎、异常检测、RiskScoring；  
- AI：可插拔 LLM（如 OpenAI / 通义）与向量库（Pinecone）；  
- 边界：`app → server → lib`，Key 仅服务端；没有 Key 也能演示确定性路径。

---

## 第 8 页｜数据来源

三类数据：

1. **财务流水输入**——用户上传 Excel/CSV；演示样例是 `fixtures/demo-financial-audit.csv`，内含重复发票、缺审批、金额离群等可控风险点；  
2. **制度知识库**——企业自建制度条目（制度名、条款号、正文），供 RAG 引用，避免空泛建议；  
3. **审计过程产物**——任务、Issue、证据快照、规则版本、工单日志与报告写入 Supabase，按用户与角色隔离。

所以评委既可以看公开样例，也可以现场上传验证。

---

## 第 9 页｜预期价值

我们希望把「抽检运气」变成可解释、可分派、可验收的审计产能：

- **覆盖率**：同一套规则对整批流水扫描，高风险优先人工复核；  
- **证据力**：发现即带凭证与制度条款，降低复核成本；  
- **闭环率**：整改不再断在邮件里，验收过程可追溯；  
- **可信度**：规则判风险、AI 只解释，核心能力不依赖 LLM 是否可用。

---

## 第 10 页｜推广可能

推广分三步：

- **近期**：内审或财务合规试点，用公开 fixture 加现场上传证明可复现；无 LLM 也能演示；  
- **中期**：对接主数据源，按期间自动抽检；AI 解释经人工确认后门闩入档；  
- **远期**：再考虑多法人规模化、对接 GRC/OA、加深行业规则包——先闭环，再平台化。

以上是 AuditLens AI 的作品说明。欢迎评委就规则设计、RAG 策略或现场操作提问。谢谢大家。

## 备用 Q&A（30 秒答法）

| 可能提问 | 答法要点 |
|----------|----------|
| AI 会不会误报？ | 规则先判；人可标误报；LLM 不决定是否风险 |
| 数据安全？ | Supabase RLS 按用户/角色隔离；Key 仅服务端 |
| 和传统审计软件比？ | 聚焦「流水风险发现 + 整改闭环」，不做全量会计系统 |
| 没配 LLM 能演示吗？ | 能——规则/异常/评分/报告完整；RAG 优雅降级 |
| 如何证明不是假数据？ | Demo fixture 公开；现场上传即跑完整流水线 |
